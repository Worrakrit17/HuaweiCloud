1. Service การบริการหลักของ Huawei Cloud

เจาะลึก 11 หมวดหมู่บริการคลาวด์ครอบคลุมตั้งแต่ระดับโครงสร้างพื้นฐาน ฐานข้อมูล ปัญญาประดิษฐ์ ไปจนถึงความปลอดภัย

1.1.1

IaaS: Infrastructure as a Service

  • Elastic Cloud Server (ECS): บริการเครื่องเสมือน (Virtual Server on Demand) ปรับขนาด vCPU, RAM ได้ยืดหยุ่น
  • Bare Metal Server (BMS) / Flexus: เซิร์ฟเวอร์กายภาพเฉพาะ ไร้ Hypervisor ประสิทธิภาพสูงสุดสำหรับงาน Mission-critical
  • Auto Scaling (AS): ระบบปรับเพิ่ม/ลดจำนวน ECS อัตโนมัติตาม Traffic
1.1.2

CaaS: Container as a Service

  • Cloud Container Engine (CCE): บริการบริหารจัดการ Kubernetes เกรดองค์กรแบบ Managed
  • Software Repository for Container (SWR): คลังเก็บ Container Images ปลอดภัยสูง
  • Cloud Container Instance (CCI): Serverless Container รันได้ทันทีไม่ต้องจัดการโหนด
1.1.3

PaaS: Platform as a Service

  • ServiceStage: แพลตฟอร์มบริหาร Application Lifecycle รองรับ Microservices และ DevOps
  • AppCube: แพลตฟอร์ม Low-Code เร่งการสร้างแอปพลิเคชันและ เวิร์กโฟลว์ธุรกิจ
1.1.4

FaaS: Function as a Service

  • FunctionGraph: บริการประมวลผลแบบ Serverless ประมวลผลตาม เหตุการณ์ (Event-driven) คิดค่าบริการตามจริงเป็นมิลลิวินาที
1.1.5

DBaaS: Database as a Service

  • RDS: Managed Relational DB (MySQL, PostgreSQL, MS SQL)
  • GaussDB: Enterprise Distributed DB ความปลอดภัย CC EAL4+
  • TaurusDB: Cloud-native MySQL ความเร็วสูง
  • GeminiDB: Managed Multi-model NoSQL (Cassandra, Mongo, Redis)
1.1.6

Security & Identity

  • IAM: บริหารจัดการสิทธิ์ ตัวตน และสิทธิ์การเข้าถึงทรัพยากร
  • WAF: ป้องกันเว็บจากการโจมตี OWASP Top 10, SQL Injection, XSS
  • HSS: ความปลอดภัยระดับโฮสต์ สแกนหาช่องโหว่และมัลแวร์
  • SecMaster: ศูนย์ SOC อัจฉริยะวิเคราะห์ภัยคุกคามด้วย AI
1.1.7

Internet of Things (IoT)

  • IoTDA: แพลตฟอร์มศูนย์กลางเชื่อมต่อและจัดการอุปกรณ์ IoT รองรับ MQTT, CoAP, HTTP
  • 5G + Cloud Integration: โซลูชันคลาวด์ร่วมกับ 5G เช่น Smart Healthcare (กรณีศึกษา รพ.ศิริราช)
1.1.8

STaaS: Storage as a Service

  • OBS: Object Storage ทนทาน 99.999999999% สำหรับรูปภาพ วิดีโอ Static Web
  • EVS: Block Storage ประสิทธิภาพสูง Latency ต่ำสำหรับ ECS/BMS
  • SFS: Shared File Storage (NAS) ผ่าน NFS/CIFS
  • CBR: บริการสำรองและกู้คืนข้อมูลอัตโนมัติ
1.1.9

Big Data & Analytics

  • DLI: Serverless Big Data คิวรีด้วย Spark, Flink, SQL
  • DWS: Enterprise Data Warehouse รองรับข้อมูลระดับ Petabyte
  • MRS: Managed Big Data Platform (Hadoop, Spark, Hive)
  • DataArts Studio: แพลตฟอร์มบริหาร Data Governance แบบครบวงจร
1.1.10

BCaaS: Blockchain as a Service

  • Huawei Cloud Blockchain Service (BCS): แพลตฟอร์มบล็อกเชนระดับองค์กร ปรับใช้เครือข่ายบล็อกเชนได้รวดเร็ว ปลอดภัย และรองรับธุรกรรมความเร็วสูง
1.1.11

Load Balancer as a Service (LBaaS)

  • Elastic Load Balance (ELB): บริการกระจายปริมาณการจราจรข้อมูล (Traffic) ไปยังเซิร์ฟเวอร์ปลายทางหลายเครื่องโดยอัตโนมัติ เพิ่มความพร้อมใช้งานสูง (High Availability) และความทนทานของระบบ ทั้งในระดับ Layer 4 (TCP/UDP) และ Layer 7 (HTTP/HTTPS)
