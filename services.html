1. Service บริการหลักของ Huawei Cloud (11 หมวดบริการ)

รวบรวมและวิเคราะห์โครงสร้างบริการหลัก IaaS, CaaS, PaaS, FaaS, DBaaS, Security, IoT, STaaS, Big Data, Blockchain และ LBaaS

1.1 IaaS: Infrastructure as a Service

ECS (Elastic Cloud Server) เซิร์ฟเวอร์เสมือนบนคลาวด์ ปรับเปลี่ยน vCPU, RAM และดิสก์ได้ยืดหยุ่น รองรับทั้ง General Computing, Memory-Intensive, Compute-Intensive และ GPU/NPU Acceleration
BMS (Bare Metal Server) / Flexus BMS เซิร์ฟเวอร์กายภาพเฉพาะบุคคล ไร้ Virtualization Overhead สำหรับภาระงานวิกฤต ส่วน Flexus เป็นคลาวด์ขนาดเบา คุ้มค่า เหมาะสำหรับ SMEs และเว็บไซต์องค์กร
AS (Auto Scaling) ระบบปรับเพิ่ม-ลดจำนวนอินสแตนซ์ ECS และแบนด์วิดท์อัตโนมัติตามนโยบาย (Alarm-based / Scheduled / Periodic) ทำงานร่วมกับ ELB ช่วยลดต้นทุน

1.2 CaaS: Container as a Service

CCE (Cloud Container Engine) บริการจัดการ Kubernetes เกรดองค์กร รองรับสถาปัตยกรรม x86 และ ARM (Kunpeng) ช่วยปรับใช้อัตโนมัติและขยายสเกลรวดเร็ว
SWR (Software Repository for Container) คลังเก็บ Container Images ความปลอดภัยสูง สแกนหาช่องโหว่อัตโนมัติ ควบคุมสิทธิ์เข้มงวด เชื่อมต่อกับ CCE ได้ไร้รอยต่อ
CCI (Cloud Container Instance) บริการ Serverless Container สามารถรัน Container (Docker Image) ได้ทันทีโดยไม่ต้องจองหรือจัดการโหนดเซิร์ฟเวอร์ คิดค่าบริการตามจริง

1.3 PaaS: Platform as a Service

ServiceStage แพลตฟอร์มบริหารจัดการวงจรชีวิตแอปพลิเคชัน (Microservices, Spring Cloud, Go-Micro) และกระบวนการ CI/CD DevOps
AppCube แพลตฟอร์ม Low-Code Development มีเครื่องมือ Drag-and-Drop ช่วยเร่งสร้างแอปพลิเคชันธุรกิจลดเวลาพัฒนาเหลือเพียงไม่กี่สัปดาห์

1.4 FaaS: Function as a Service

FunctionGraph

บริการประมวลผลแบบ Serverless (Event-driven Computing) ผู้พัฒนาเพียงเขียนโค้ดฟังก์ชัน (Python, Node.js, Java, Go)

  • ทำงานอัตโนมัติเมื่อเกิด Event (เช่น อัปโหลดไฟล์บน OBS, API Request, DB Change)
  • คิดค่าบริการตามจำนวนครั้งที่เรียกใช้และเวลาประมวลผลจริงระดับมิลลิวินาที

1.5 DBaaS: Database as a Service

RDS รองรับ MySQL, PostgreSQL และ MS SQL Server มี Auto-backup, Read Replicas และ Auto-failover
GaussDB ฐานข้อมูลระดับองค์กรแบบกระจาย มาตรฐาน CC EAL4+ ทนทานระดับ Zero Data Loss เหมาะสำหรับสถาบันการเงินและภาครัฐ
TaurusDB Cloud-native MySQL ความเร็วสูง แยกส่วน Compute & Storage ให้ประสิทธิภาพเร็วกว่า MySQL ดั้งเดิมหลายเท่า
GeminiDB NoSQL แบบ Multi-model รองรับ API ของ Cassandra, MongoDB, Redis และ InfluxDB ย้ายระบบได้ไม่ต้องแก้โค้ด

1.6 Security & Identity

IAM: จัดการสิทธิ์การเข้าถึง MFA และ Single Sign-On
WAF: ป้องกันOWASP Top 10, SQL Injection, Bot Attack
HSS: ป้องกันโฮสต์ สแกนช่องโหว่ ป้องกัน Ransomware
SecMaster: ศูนย์ควบคุม SOC วิเคราะห์ภัยคุกคามด้วย AI

1.7 Internet of Things (IoT)

IoT Device Access (IoTDA) ศูนย์กลางเชื่อมต่อและบริหารจัดการอุปกรณ์ IoT ผ่าน MQTT, CoAP, LwM2M, HTTP ส่งข้อมูลสู่ Analytics ได้ปลอดภัย
5G + Cloud Integration ผสาน 5G Ultra-low Latency กับคลาวด์ ตัวอย่างกรณีศึกษา Smart Healthcare โรงพยาบาลศิริราช ส่งภาพถ่ายทางการแพทย์เรียลไทม์

1.8 STaaS: Storage as a Service

OBS (Object Storage) เก็บ Unstructured Data ทนทานสูง 99.999999999% (11 Nines) ทำ Static Website Hosting ได้
EVS (Elastic Volume) Block Storage Latency ต่ำ สำหรับต่อกับ ECS/BMS มีดิสก์ High I/O และ Ultra-high I/O SSD
SFS (Scalable File) ระบบ NAS แชร์ไฟล์ข้ามหลายอินสแตนซ์ผ่าน NFS / CIFS ขยายความจุได้ทันทีโดยไม่ต้องหยุดระบบ
CBR (Cloud Backup) สำรองและกู้คืนข้อมูลอัตโนมัติ ทำ Backup/Snapshot ป้องกันความเสียหายและ Ransomware

1.9 Big Data & Analytics

  • DLI: Serverless Big Data (SQL, Spark, Flink)
  • DWS: Enterprise Data Warehouse สถาปัตยกรรม MPPs
  • MRS: Managed Hadoop, Spark, Hive, Presto
  • DataArts Studio: Data Governance ครบวงจร

1.10 BCaaS: Blockchain

BCS (Blockchain Service) แพลตฟอร์มบล็อกเชนสำเร็จรูปเกรดองค์กร (Hyperledger Fabric) รองรับ TPS สูง เหมาะสำหรับ Supply Chain และธุรกรรมการเงิน

1.11 LBaaS: Load Balancer

ELB (Elastic Load Balance) กระจาย Traffic เพิ่ม High Availability รองรับ Layer 4 (TCP/UDP) และ Layer 7 (HTTP/HTTPS) พร้อม Health Check ตรวจเช็กเซิร์ฟเวอร์อัตโนมัติ
