5. Certification Path & แนวทางการพัฒนาทักษะ

โครงสร้างใบรับรองความรู้มาตรฐานสากล 3 ระดับ และการประยุกต์ใช้สำหรับนิสิต มหาวิทยาลัยมหาสารคาม

5.1 - 5.3 โครงสร้างเส้นทางการรับรองความรู้มาตรฐานสากล

HCIA

Associate Level (ระดับพื้นฐาน)

เป้าหมาย: ปูพื้นฐานเทคโนโลยีคลาวด์ สถาปัตยกรรมระบบเบื้องต้น และบริการ Compute, Storage, Network, DB

กลุ่มเป้าหมาย: นิสิต นักศึกษา ผู้เริ่มต้นสายงานไอที Entry-level Cloud Engineers, System Admins

HCIP

Professional Level (ระดับผู้เชี่ยวชาญ)

เป้าหมาย: ออกแบบสถาปัตยกรรมคลาวด์ซับซ้อน, Cloud Migration, High Availability, Disaster Recovery, Security

กลุ่มเป้าหมาย: Cloud Solution Architects, Senior System Engineers, DevOps Engineers

HCIE

Expert Level (ระดับผู้เชี่ยวชาญขั้นสูง)

เป้าหมาย: ประยุกต์ความรู้ขั้นสูง วางสถาปัตยกรรม Enterprise, Hybrid Cloud, Troubleshooting และวางกลยุทธ์ไอทีองค์กรใหญ่

กลุ่มเป้าหมาย: Principal Cloud Architects, CTO, ที่ปรึกษาไอทีองค์กร

5.4 แนวทางการพัฒนาทักษะสำหรับนิสิตระดับปริญญาตรี (รายวิชา 0904327 มมส)

1. สถาบัน Huawei ICT Academy เข้าร่วมโครงการเพื่อเข้าถึงคอร์สเรียนมาตรฐานสากล สื่อการเรียนรู้ออนไลน์ และโควตาสอบใบรับรองฟรี
2. เริ่มต้นสอบระดับ HCIA-Cloud Service สร้างรากฐานความรู้สำหรับการเป็น Cloud Engineer, DevOps หรือ System Administrator เพิ่มโอกาสประกอบอาชีพ
3. ลงแข่งขัน Huawei ICT Competition เข้าร่วมเวทีการแข่งขันระดับประเทศและระดับโลก เพื่อประยุกต์ใช้ความรู้กับโจทย์จริง เพิ่ม Profile และโอกาสเข้าทำงานในอุตสาหกรรมดิจิทัล
