5. Certification Path (เส้นทางใบรับรองวิชาชีพ)

โครงสร้างคุณวุฒิวิชาชีพไอทีจาก Huawei Cloud เพื่อเพิ่มทักษะและความก้าวหน้าในสายงาน

5.1

ระดับของใบรับรองวิชาชีพ (Certification Hierarchy)

ระดับ Associate

HCIA (Huawei Certified ICT Associate)

ระดับเริ่มต้น เหมาะสำหรับนักศึกษาหรือผู้เริ่มต้นศึกษาคลาวด์ ทดสอบความรู้พื้นฐานเกี่ยวกับบริการคลาวด์ การใช้งาน Console และสถาปัตยกรรมเบื้องต้น

• รูปแบบ: ปรนัย (Multiple Choice)
• ค่าสอบประมาณ: $200 USD
ระดับ Professional

HCIP (Huawei Certified ICT Professional)

ระดับกลาง เหมาะสำหรับ System Engineer และ Cloud Administrator ทดสอบการออกแบบ ติดตั้ง ปรับแต่ง และแก้ไขสถาปัตยกรรมคลาวด์ระดับองค์กร

• รูปแบบ: ปรนัยขั้นสูง / Scenario-based
• ค่าสอบประมาณ: $300 USD
ระดับ Expert

HCIE (Huawei Certified ICT Expert)

ระดับสูงสุด สำหรับ Cloud Architect และวิศวกรอาโส ทดสอบทักษะการออกแบบโซลูชันระดับซับซ้อน การย้ายระบบ (Migration) และความมั่นคงปลอดภัย

• รูปแบบ: ข้อเขียน + การสอบปฏิบัติ (Lab Test)
• ค่าสอบประมาณ: $1,200 USD
5.2

สายงานความเชี่ยวชาญเฉพาะทาง (Specialized Domains)

1. Cloud Service & Architecture เน้นการบริหารจัดการ Infrastructure, Networking, Security และการออกแบบระบบคลาวด์องค์กร
2. Cloud DevOp & Developer เน้นการพัฒนาแอปพลิเคชันแบบ Cloud-native, CI/CD Pipelines, Containers (CCE) และ Serverless
3. Big Data & Analytics เน้นการจัดการระบบคลังข้อมูล (Data Warehouse), Data Pipeline และการวิเคราะห์ข้อมูลขนาดใหญ่ด้วย DLI/MRS
4. Artificial Intelligence (AI) เน้นการพัฒนาโมเดล AI, Machine Learning, Deep Learning และการใช้งาน ModelArts แพลตฟอร์ม
5.3

ขั้นตอนการเตรียมตัวและการจัดสอบ

1

เรียนรู้ผ่าน Huawei Talent Portal

เข้าศึกษาคอร์สเรียนออนไลน์ e-Learning และ e-Lab ฟรีผ่านแพลตฟอร์มการเรียนรู้ทางการของ Huawei Talent

2

จองรอบสอบผ่าน Pearson VUE

สามารถลงทะเบียนเลือกวัน เวลา และศูนย์สอบมาตรฐานของ Pearson VUE หรือเลือกสอบออนไลน์ผ่านระบบจัดสอบไกลได้

3

อายุและการต่ออายุใบรับรอง

ใบรับรองมีอายุ 3 ปี สามารถต่ออายุ (Recertify) ได้โดยการสอบในระดับเดียวกันหรือระดับที่สูงกว่าก่อนหมดอายุ
